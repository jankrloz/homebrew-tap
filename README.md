# homebrew-tap

Personal Homebrew tap for JC ([@jankrloz](https://github.com/jankrloz)).

## Installation

```bash
brew tap jankrloz/tap
brew install vanguard
```

Or install directly in one step:

```bash
brew install jankrloz/tap/vanguard
```

## Formulas

| Formula | Description |
|---|---|
| [`vanguard`](Formula/vanguard.rb) | Interactive, biometric-secured vulnerability shield & package orchestrator (`vg`) |
